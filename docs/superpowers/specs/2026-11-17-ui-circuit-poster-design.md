# UI 개편 설계: 서킷 포스터

**문제.** 외부 리뷰에서 "AI가 만든 듯한 UX"라는 지적을 받았다. 원인은 화면 전체에 반복되는
파랑→분홍→주황 그라데이션 알약 버튼, 반투명 유리 패널, 보라색 빛망울 배경, 이모지 아이콘,
위계 없는 정보(레이서 카드 8장 × 스탯 5줄), 설명하는 문구(기술 스펙 푸터, 조작키 표)다.
레이싱 게임이라는 것을 알려주는 모양이 UI 어디에도 없다.

**목표.** UI 전체를 "서킷 포스터" 스타일 하나로 다시 입힌다. 모터스포츠 포스터처럼 검정 바탕에
레이스 옐로 하나만 강조색으로 쓰고, 기울어진 패널·체커·번호판을 반복 소품으로 삼는다. 화면마다
가장 중요한 정보 하나가 먼저 보이게 한다.

**비목표.** 게임 규칙, 주행 감각, 3D 카트·트랙, 서버 함수는 바꾸지 않는다. 화면 흐름(로비 →
레이서 → 서킷 → 레이스 → 결과)도 그대로다.

이 문서는 2026-11-17 업데이트의 다섯 덩어리 중 첫 번째다. 나머지(카트 외형, 주로, 진행 시스템,
고스트·주간 리그)는 각자 스펙을 따로 쓴다.

## 확정 사항 (2026-11-17, 소유자와 합의)

| 질문 | 결정 |
|---|---|
| 범위 | 전체 개편. 모든 화면과 HUD |
| 스타일 | A "서킷 포스터" (B 토이 카트, C 네온 아케이드는 탈락) |
| 강조색 | 레이스 옐로 하나. 빨강은 잠금·경고·리타이어 상태에만 |
| 유지하는 색 | 순위 금·은·동, 팀 레드/블루, HUD의 아군 파랑·상대 빨강 (2026-09-09 결정) |
| 아이콘 | 이모지·화살표 문자 전부 제거, 코드로 그린 선 아이콘으로 교체. 에셋 파일 0개 유지 |
| 로고 | 그라데이션 로고를 버리고 같은 스타일의 워드마크로 다시 제작 |
| 조작키 표 | 로비에서 제거. 설정 안으로 옮기고 첫 레이스 로딩 화면에 한 번만 표시 |
| 마케팅 에셋 | 이번 범위 밖. 업데이트를 올리기 직전에 따로 다시 제작 |

기울여 그린다.

## 2. 모양 규칙

- **평행사변형은 `clip-path`로 그린다.**
  `clip-path: polygon(var(--slant) 0, 100% 0, calc(100% - var(--slant)) 100%, 0 100%)`.
  `transform: skew`는 쓰지 않는다. 글자가 흐려지고 터치 영역이 어긋나기 때문이다. 글자는 항상
  똑바로 둔다(이탤릭 글꼴로만 기울인다).
- **평행사변형을 쓰는 곳**: 버튼, 탭·세그먼트, HUD 상자(랩, 타이머, 순위), 칩.
- **큰 패널**(설정, 기록, 차고, 결과, 일시정지)은 직사각형이다. 내용이 스크롤되기 때문이다.
  대신 왼쪽에 6px 노란 띠, 위에 8px 체커 띠를 두고 오른쪽 위 모서리를 `--slant`만큼 깎는다.
- **불투명**. `backdrop-filter`, 반투명 배경, `box-shadow` 번짐, `text-shadow` 번짐을 쓰지 않는다.
  레이스 중 HUD 상자만 예외로 `--asphalt`를 88% 불투명도로 깔 수 있다(주로가 가려지지 않게).
- **그라데이션 금지**. 예외는 체커 무늬를 만드는 `repeating-linear-gradient`와 서킷 썸네일의
  하늘뿐이다.

| 부품 | 모양과 상태 |
|---|---|

| `.panel-title` | 흰색 이탤릭, 그라데이션 글자·그림자 제거 |
| `.btn` | 평행사변형, `--panel-hi` 바탕, 흰 글자. 호버: `--line`. 누름: 2px 아래로 |
| `.btn.primary` | `--yellow` 바탕, `--on-yellow` 글자. 한 화면에 하나만 |
| `.btn.start` | `.primary`의 큰 판. 움직이는 그라데이션과 빛 훑기 애니메이션 삭제 |
| `.btn.ghost` | `--asphalt` 바탕, 아래 2px `--line` 선 |
| `.btn.danger` | 왼쪽 6px `--red` 띠 |

| `.chip` (구 `.pill`) | 작은 평행사변형, `--line` 바탕. 체급 칩은 글자색 대신 앞에 8px 색 사각형을 붙인다 |
| `.seg` | 모드·난이도·컵 선택용 세그먼트. 평행사변형이 틈 없이 이어지고 선택된 칸만 `--yellow` |
| `.stat` | 스탯 막대. 5칸짜리 블록(켜짐 `--yellow`, 꺼짐 `--line`). 그라데이션 막대 삭제 |
| `.plate` | 번호판. 흰 바탕 + 검정 이탤릭 숫자 + 2px 검정 테두리. 레이서 번호(1~8)와 결과 화면의 내 순위에 쓴다 |
| `.checker` | 8px 체커 띠. 패널 머리, 구분선, 로딩 진행 바의 채움 |
| `.lock` | `--red` 칩 + 자물쇠 아이콘 |
| `kbd` | 각진 키 모양, `--panel-hi` 바탕, 아래 2px `--line` |
| `.toast` | `--asphalt` 불투명 + 왼쪽 노란 띠. 오류는 빨간 띠 |

터치 대상은 최소 44×44px이다. `prefers-reduced-motion`이면 패널 미끄러짐 연출을 끈다.

## 4. 아이콘 (`src/ui/icons.ts` 신설)

24×24 격자, 선 굵기 2, `currentColor`를 쓰는 인라인 SVG다. `icon(name)`이 `SVGElement`를
돌려준다. DOM에서 아이콘과 글자를 따로 붙이고, 번역 문자열에는 아이콘을 넣지 않는다.

필요한 아이콘: trophy(기록), wrench(차고), gear(설정), flag(레이스·서킷), calendar(오늘의 도전),
users(온라인), lock, chevron-left(뒤로), chevron-right(다음·포커스), spray(도색), ad(광고 보기),
cart(구매), sound, mute, pause, play, rotate-phone, star, check, close.
진행 시스템용으로 coin, flame(연속 접속), target(미션)도 함께 만든다.

번역 파일(`core/locales/ko.ts`, `en.ts`)에서 이모지와 화살표를 뺀다:
`menu.paint`, `menu.back`, `menu.continue`, `mute`, `v8.lock.watch`, `v8.lock.buy`,
`lb.setNickname`, `lb.button`, `settings.nudge`. 터치 일시정지 버튼의 `❚❚`, 화면 회전 안내의
`📱`, 난이도 별 `★☆`도 아이콘으로 바꾼다. `pause.hint`의 방향키 표기는 `kbd`로 그린다.

## 5. 로고와 배경

**로고.** `MainMenu.ts`의 `.logo`를 워드마크로 다시 만든다. "DRIFT DASH"는 흰색 이탤릭,
"GP"는 노란 번호판 안에 검정 글자, 아래에 체커 띠. 그라데이션, 글자 그림자, 광택을 없앤다.
부제 `title.sub`는 작은 `--ink-dim` 글자로 남긴다. 로딩 화면도 같은 로고를 쓴다.

**로비 배경** (`game/MenuBackdrop.ts`). 3D 카트 회전 전시는 유지한다.
- 빛망울 먼지(`dust` Points)와 별(`stars` Points)을 삭제한다.
- 하늘 그라데이션과 안개 색을 `--asphalt` 단색으로 바꾼다.
- 바닥을 어두운 아스팔트로 바꾸고, 빛나는 고리 대신 출발 그리드를 그린다: 노란 칸 선, 흰 출발선,
  체커 띠.
- 카트를 비추는 조명은 유지하되 색 조명(분홍·파랑)을 흰색 주광 + 약한 노란 보조광으로 바꾼다.
  조명 개수는 바꾸지 않는다(셰이더 재컴파일 방지).

## 6. 화면별 변경

### 로비 (타이틀)
- 조작키 표(`legend.*`)와 기술 문구(`title.version`)를 화면에서 뺀다. `title.version` 키는 삭제한다.
- 빌드 표시(`build MM/DD HH:MM · sha`)는 QA에 쓰이므로 남긴다. 오른쪽 아래, `--ink-faint`,
  첫 입력 전까지만 보이는 지금 동작 그대로다.
- 버튼: "레이스"만 `.btn.start`로 크게. 오늘의 도전, 차고, 기록, 설정은 `.btn` 작은 판에
  아이콘 + 글자. 온라인 버튼은 `ONLINE_ENABLED`가 꺼져 있으면 지금처럼 숨긴다.
- 도구 스크립트가 쓰는 클래스명(`.single-toggle`, `.online-toggle`, `.settings-toggle`,
  `.records-toggle`)은 유지한다.
- 진행 시스템이 넣을 프로필 바(상단)와 미션 버튼 자리를 레이아웃에 비워 둔다. 내용은 만들지 않는다.

### 조작법 안내
- 설정 패널에 "조작법" 구획을 추가하고 `legend.*` 표를 옮긴다. 터치 기기에서는 터치 조작 설명을 보여준다.
- 첫 레이스의 로딩 화면에 같은 표를 한 번 보여준다. 봤다는 표시는 `settingsStore`에
  `tkr.seenControls`로 저장한다. 저장소를 못 쓰면 매번 보여주지 않고 건너뛴다.

### 레이서 선택
- 카드: 썸네일, 번호판, 이름, 체급 칩, (잠겼으면) 잠금 칩만 남긴다. 카드의 스탯 5줄을 뺀다.
- 썸네일 바탕의 대각선 그라데이션을 레이서 대표색 단색으로 바꾼다.
- 아래 상세 칸: 선택한 레이서의 이름(크게), 한 줄 설명, 스탯 5개(`.stat`), 도색·뒤로·다음 버튼.
- "1 / 2 단계"(`menu.step1`) 문구를 빼고 키를 삭제한다.
- 선택된 카드는 빛나는 테두리 대신 노란 3px 테두리 + 왼쪽 위 노란 삼각 표시.

### 서킷 선택
- 카드: 썸네일(테마 칩 포함), 이름, 난이도 별, 랩 수 칩. 등급 칩(루키·프로·엑스퍼트)은 별과
  겹치므로 뺀다.
- 아래 줄: 모드 / 난이도 / 그랑프리 세 구획을 각각 제목 + `.seg`로 정리한다. 설명 문장
  (난이도 설명, 컵 해금 조건)은 뺀다. 잠긴 컵을 누르면 해금 조건을 토스트로 알려준다.
- "2 / 2 단계"(`menu.step2`) 문구를 빼고 키를 삭제한다.

### 결과
- 맨 위에 내 순위를 큰 번호판(`.plate`)으로 보여준다.
- 순위표 행은 불투명 `--panel`. 내 행은 왼쪽 노란 띠. 1~3위 순위 숫자는 금·은·동.
- 버튼: "다시 레이스"(`.primary`), "서킷 변경", "로비". 기록은 아이콘 버튼으로 줄인다.
- 순위표와 버튼 사이에 진행 시스템의 보상 줄이 들어갈 자리를 비워 둔다.

### 레이스 HUD
- 미니맵을 가운데 위에서 **왼쪽, 순위표 아래**로 옮긴다. 터치 모드에서는 순위표를 상위 3명 +
  나(4줄)로 줄이고 그 아래에 작은 미니맵을 둔다. 왼쪽 아래 조향 스틱과 겹치지 않아야 한다.
- 가운데 순위 표시는 순위가 바뀔 때만 1초 띄운다. 왼쪽 아래 큰 순위는 번호판 스타일로 유지한다.
- 빈 아이템 칸: 2px 점선 `--line` 테두리의 빈 슬롯. 아이템이 있으면 `--panel` 불투명 + 노란 테두리.
- 랩·타이머: 평행사변형 상자, 라벨은 노랑, 숫자는 흰 이탤릭.
- 속도계 호: 파랑 → `--yellow`.
- 터치 버튼(드리프트, 아이템, 일시정지): `--asphalt` 88% + 2px `--line` 테두리, 누르면 노란 테두리.
- 미러, 팀 집계, 스타트 차지 게이지, 드래프트 미터: 색만 토큰으로 바꾼다. 아군 파랑·상대 빨강은 유지.
- HUD는 값이 바뀔 때만 DOM을 쓰는 지금 규칙(`docs/ARCHITECTURE.md` 3절)을 지킨다.

### 나머지 패널
차고, 기록, 설정, 일시정지, 오늘의 도전, 잠금 시트, 아이템 가이드, 온라인 패널, 알림, 로딩,
화면 회전 안내는 3절의 공통 부품으로 다시 입힌다. 구조는 바꾸지 않는다. 로딩 진행 바는 체커
무늬로 채운다.

## 10. 구현 중 판단 (2026-11-17, 브랜치 `ui-circuit-poster`)

스펙과 실제 코드가 맞지 않거나 스펙이 정하지 않은 곳에서 내린 판단이다. 게임 규칙과 화면 흐름은
바꾸지 않았다.

### 모양과 색

- **기울기 폭.** `--slant: 14px`은 높이 약 66px에서 12도다. 높이가 낮은 부품에 그대로 쓰면 각도가
  35도까지 눕는다. 각도를 12도 안팎으로 맞추려고 부품 안에서 `--slant`를 줄였다(칩 4px, 세그먼트
  8px, 버튼 10px, 시작 버튼 14px).
- **체커.** 전역 변수 하나로 두지 않고 `.checker` 클래스(와 패널 머리 띠)에 그라데이션을 직접 적었다.
  CSS 변수는 선언된 곳에서 값이 굳어서, 부품마다 칸 크기(`--sq`)를 바꿀 수 없었기 때문이다.
- **패널 머리 띠.** 패널이 스크롤 컨테이너라서 띠를 `position: sticky` 가상 요소로 그렸다. 내용이
  띠 아래로 지나간다. 왼쪽 노란 띠는 `border-left`다.
- **`--green` 삭제.** 스펙의 삭제 목록에는 없지만 강조색을 하나로 줄이는 취지에 맞춰 지웠다. 쓰던 곳은
  노랑(차고 패스 보유, 준비 완료, 순위 상승)이나 흰색(미러의 "내 아이템" 테두리)으로 바꿨다.
- **파란 등껍질 경고.** 미러 테두리의 파랑(`#3f7fff`)은 남겼다. 아이템 고유색이고 "피할 수 없다"는
  뜻을 구분해 주기 때문이다. 토큰 밖의 색은 이것과 체급 칩의 색 사각형 3개뿐이다.
- **가림막.** 패널 뒤를 어둡게 덮는 층(`rgba(21,22,26,0.82)`, 일시정지 0.72)은 반투명이다. 불투명
  규칙은 패널·버튼 같은 표면에 대한 것으로 보고, 뒤 화면(로비, 멈춘 레이스)이 어둡게 보이는 지금
  구조를 유지했다. 블러는 없다.
- **`box-shadow`.** 번짐 없는 inset 선(ghost 버튼 밑줄, 키 모양, 팀 집계 밑줄)으로만 쓴다.

### 포커스

- 버튼은 스펙대로 노란 채움 + 갈매기 표시, 주 버튼은 흰색으로 뒤집는다. **카드와 세그먼트는 스펙에
  없어서** 카드는 흰 외곽선, 세그먼트는 흰 채움으로 정했다(선택 = 노랑과 구분).
- **터치 기기**(`#ui.touch`)에서는 포커스 표시를 끈다. 손가락에는 커서가 없는데, 로비의 "레이스"가
  기본 포커스라서 폰에서 늘 흰색으로 보이는 문제가 있었다.
- **관찰:** 키보드로 다른 버튼에 포커스를 옮기면 노란 주 버튼과 노란 포커스 버튼이 함께 보인다.
  갈매기 표시로 구분되지만 한눈에는 헷갈릴 수 있다. 스펙 그대로 두었고, 바꾼다면 포커스를 전부
  흰색으로 통일하는 방법이 있다.

### 로비와 배경

- **"레이스" 문구.** `lobby.race` 키를 추가했다. `ONLINE_ENABLED`가 켜지면 지금처럼 "싱글 레이스"
  (`lobby.single`)를 쓴다.
- **빌드 표시가 두 개였다.** `buildTag.ts`의 `build MM/DD HH:MM · sha`(오른쪽 아래, 첫 입력까지)는
  색만 `--ink-faint`로 바꿨다. 로비 문구에 붙어 있던 빌드 ID(`__BUILD_ID__`, 소스 해시 포함)는 QA가
  배포본과 소스를 맞춰 보는 값이라 왼쪽 아래에 작게 남겼다. 폰 가로에서는 전처럼 숨긴다.
- **프로필 바와 미션 버튼 자리.** 상단에 빈 `.lobby-profile`(높이만 차지)을 두었고, 작은 버튼은
  2열 격자(`.lobby-grid`)라서 미션 버튼이 한 칸으로 들어온다.
- **배경.** 넓은 발판 단을 없애고 턴테이블을 낮췄다(출발 그리드의 선이 가려져서). 조명은 개수와
  종류를 유지하고 색을 스펙대로 바꿨는데, **세기도 낮췄다**(스폿 60 → 9, 주광 2.6 → 1.6, 점광
  38 → 10, 환경맵 카드는 회색). 무광 아스팔트 바닥과 카트의 크롬·헬멧이 블룸으로 하얗게 번졌기
  때문이다. 카트의 금속 부품에는 작은 반사광이 아직 남는다.
- **키보드 이동.** 로비가 2열 격자가 되어 상하는 한 줄, 좌우는 한 칸씩 움직인다.

### 선택 화면

- 레이서 카드의 임시 그림(헬멧·바퀴, 그라데이션으로 그린 것)을 지웠다. 썸네일이 준비되기 전
  한두 프레임은 대표색 바탕만 보인다.
- 서킷 썸네일은 하늘 그라데이션만 남기고 바닥을 단색으로, 지평선의 안개 띠를 삭제했다.
- 폰 가로에서는 랩 수 칩을 썸네일 위(오른쪽 위)에 얹어 카드 한 줄을 줄였다. 두 줄의 카드가
  스크롤 없이 보인다.
- 번역 키: 스펙에 적힌 것만 지웠다. `tier.*`, `cup.blurb`는 쓰는 곳이 없어졌지만 남겼고,
  `cup.best`는 컵 칩의 툴팁으로 쓴다.
- 기존 버그 하나를 고쳤다: "레이스 시작" 버튼에 마우스를 올리면 포커스 줄이 컵 줄(3)로 잡히던 것을
  시작 버튼 줄(4)로.

### 결과와 패널

- **순위표 행.** 스펙은 불투명 `--panel`인데 패널도 같은 색이라, 행 사이에 `--line` 구분선을 넣고
  내 행은 `--panel-hi` + 노란 띠로 했다. 기록·온라인·오늘의 도전 목록도 같은 방식이다.
- **번호판.** 1~3위는 금·은·동 바탕, 리타이어는 빨간 바탕에 DNF. 번호판 옆 제목("3위", "우승!")은
  기존 문구를 그대로 두어 숫자가 두 번 보인다.
- 결과와 설정 패널의 버튼 줄은 아래에 붙여(`sticky`) 목록이 길어도 닿게 했다.
- 색종이는 노랑·흰색·회색으로 줄였다.
- 문구 값 변경: `results.changeTrack` "서킷 변경", `results.mainMenu` "로비". `pause.hint`는
  `pause.hint.resume/move/select` 세 키로 나눴다. `loading.subtitle`에서 `{stars}`를 뺐다.
  추가한 키: `lobby.race`, `settings.controls`, `legend.touch.*` 4개.
- 차고의 잠긴 항목은 글자 "잠김" 대신 빨간 자물쇠 칩(툴팁에 문구)이다.

### HUD와 터치

- **가운데 순위 표시**는 원래도 순위가 바뀔 때만 1초 떴다. 연달아 바뀌면 겹쳐 쌓이던 것을 새 표시가
  앞의 것을 대신하게 했고, 완주 배너가 떠 있는 동안은 숨긴다. 역주행 표시와 겹치지 않게 위치를 나눴다.
- **터치 순위표 4줄**은 CSS로 했다(3위 밖의 줄을 숨기되 내 줄은 남김, 내가 3위 안이면 4번째 줄을
  채움). 순위표 코드는 건드리지 않았다. `:has()`가 없는 브라우저에서는 내가 3위 안일 때 3줄이 된다.
- **조향 스틱 영역은 바꾸지 않았다**(왼쪽 45%, 위에서 18%부터). 미니맵은 왼쪽 위에 있고 스틱은
  손가락이 닿은 자리에 생기므로, 평소 엄지 위치(왼쪽 아래)에서는 겹치지 않는다. 미니맵을 직접 누르면
  그 위에 스틱이 생긴다(전에도 순위표 위에서 같았다). 영역을 줄이면 조작이 바뀌므로 손대지 않았다.
- **터치 버튼은 원형을 유지했다.** 스펙은 색만 정했고, 스틱과 짝이 되는 조작부라서 정보 상자(평행
  사변형)와 구분되게 두었다. 일시정지 버튼은 44×44 사각이다.
- **빈 아이템 칸**은 스펙대로 `--line` 점선이라 어두운 서킷(Neon)에서는 흐리다. 아이템이 들어오면
  노란 테두리로 분명해진다.
- **피격 표시**는 붉은 방사형 그라데이션 대신 빨간 테두리가 번쩍인다. **부스트 글로우 오버레이는
  삭제했다**(그라데이션이었고, 속도선과 배기 화염이 같은 정보를 준다).
- **오버드라이브** 남은 시간은 원뿔 그라데이션 테두리 대신 아이템 칸 아래의 노란 막대다.
- 미니맵은 화면 크기에 따라 줄어들며(`--map`), 줄어들어도 선 굵기가 유지되게 했다. PC에서는 순위표
  아래 약 144px, 터치에서는 84px.
- 테두리 없는 큰 글자(카운트다운, 속도, 완주)는 번지는 그림자 대신 아스팔트색 외곽선을 둘렀다.

### 조작법 안내

- 첫 레이스 로딩에서 팁 자리에 조작법 표를 한 번 보여준다. **로딩 시간은 늘리지 않았다.** 로딩이
  1~2초로 짧으면 표를 다 읽기 어렵다. 표는 설정에 항상 있다.

### 영어 표시 (2026-11-17 추가 지시: "영어도 잘 나오도록")

- **표시 글꼴에 웹폰트 Anton을 추가했다.** 스펙 1절은 글꼴을 "지금 값 그대로"라고 했지만, 지금 값의
  첫 글꼴인 Impact는 PC에만 있다. 안드로이드와 iOS에는 없어서 폰에서는 영어 제목·버튼·숫자가 얇은
  시스템 글꼴로 떨어졌다(한글은 Black Han Sans 웹폰트라 문제없었다). 캡처를 찍는 맥에는 Impact가
  있어서 화면으로는 드러나지 않았다. `--display`를 `Impact, Haettenschweiler, Anton, Black Han Sans,
  …`로 바꾸고 `index.html`의 Google Fonts 링크에 Anton(OFL)을 더했다. PC는 전과 같이 Impact로
  그리고, 폰은 같은 비율의 Anton으로 그린다. 저장소에 글꼴 파일은 없다(Black Han Sans와 같은 방식).
- 한국어 전용이던 `--display` 재정의 두 개를 없애고 한 스택으로 합쳤다.
- `tools/mobile-audit.mjs --phone-fonts`: PC 전용 글꼴을 스택에서 빼고 찍는다. 폰에서 보이는 그대로다.
  `--lang en|ko`로 한 언어만 찍을 수 있다.
- 영어에서 줄이 넘치던 두 곳을 고쳤다: 차고 탭 9개(PRESETS만 둘째 줄로 떨어짐)와 일시정지 패널의
  키 안내(ENTER만 둘째 줄).

### 확인하지 못한 것

- 온라인 패널: `ONLINE_ENABLED`가 꺼져 있어 화면으로 볼 수 없었다. CSS만 새 부품에 맞췄다.
- 치명 오류 화면(WebGL2 없음), 실제 기기, 게임패드 입력, Verse8 호스트 안에서의 기록·오늘의 도전
  목록(행이 채워진 상태)은 확인하지 못했다.
