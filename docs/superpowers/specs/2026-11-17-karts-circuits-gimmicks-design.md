## 2. 주로 기믹

전부 `TrackDefinition`의 선택 필드로 추가한다(계약: 추가만). 기믹이 없는 트랙은 지금과 똑같이 동작한다.

```ts
ramps?: { t: number; length?: number; height: number; halfWidth?: number; lateral?: number; gap?: number }[];
zones?: { from: number; to: number; kind: 'ice' | 'mud' | 'boost'; look?: 'ice' | 'mud' | 'water' | 'sand' | 'ash'; lateral?: [number, number] }[];
movers?: (
  | { kind: 'roller'; from: number; to: number; speed: number; lateral?: number; sway?: number; radius?: number; look?: 'boulder' | 'snowball' | 'lava'; phase?: number }
  | { kind: 'crosser'; t: number; period: number; speed: number; cars?: number; radius?: number; look?: 'tram' | 'cart'; phase?: number }
)[];
wallHalfWidthFactors?: number[];   // 컨트롤 포인트별 벽 거리 배수 (지름길용)
```

### 2.1 점프대와 끊긴 도로

- 점프대는 **지면 높이 함수**로 구현한다. `Track.query()`가 점프대 발판 위에서 `groundY`에 쐐기 높이를
  더한다. 카트 물리는 이미 지면 경사 속도(`groundVy`)로 떠오르므로, 끝에서 지면이 꺼지면 날아간다.
  이륙 수직 속도 ≈ 경사 × 속도. 예: 길이 10m·높이 2.5m, 22m/s → 약 0.5초 체공, 11m.
- 보이는 것: 도로 위에 쐐기 메시(윗면 갈매기 무늬, 옆면·뒷면). `builders/features.ts` 신설.
- `gap`(m)을 주면 점프대 끝부터 그 길이만큼 도로가 없다(도로·연석·갓길 메시를 비우고 노면은 `void`).
  **`voidRanges` 안에서만 허용**한다: 그 구간만 지형이 깊게 파여 있다.
- 끊긴 도로의 안전장치:
  - 떨어진 카트는 **점프대 40m 전보다 뒤의 체크포인트**에서 다시 시작한다(바로 앞에서 살아나면 속도가
    없어 계속 떨어진다). `ITrack.isRespawnSafe?(t)`를 추가하고 `RaceManager.respawn`이 안전한
    체크포인트까지 거슬러 올라간다.
  - 도로 아래로 1.5m 넘게 내려간 카트는 건너편 도로에 닿아도 올라붙지 않고 계속 떨어진다.
  - 착지 쪽 도로를 이륙 쪽보다 낮게 설계한다. 끊긴 도로 앞에는 부스트 패드를 둔다.
- **공중 묘기**: 점프대나 언덕에서 뜬 상태(홉 아님, 체공 0.15초 이상)에서 드리프트 버튼을 누르면 한 번
  묘기를 한다(차체가 한 바퀴 돈다). 착지하면 부스트 +30% 1.0초. `BoostSource`에 `'trick'`,
  이벤트 `kart:trick`, `KartState.trickTimer`. AI는 난이도에 따라 확률로 한다.

### 2.2 노면 구간

- `SurfaceType`에 `'ice'`, `'mud'` 추가.
  - 얼음: 옆 접지력이 크게 줄어든다(8 → 1.6). 최고 속도는 그대로.
  - 진흙·얕은 물·화산재: 최고 속도 ×0.72(부스트·스타 중에는 무시, 오프로드와 같은 규칙), 가속도 줄어든다.
  - `'boost'` 구간: 긴 부스트 띠. 띠 위에 있는 동안 부스트가 이어지게 한다(지금은 진입 때 한 번).
- 보이는 것: 도로 위 0.02m에 얹는 띠 메시. 종류·`look`별 색과 무늬.
- 수치는 `core/balance.ts`의 `BALANCE.track`에 둔다.

### 2.3 움직이는 장애물

- **레이스 시계의 순수 함수**로 위치가 정해진다. `ITrack.setRaceTime?(seconds)`를 추가하고 `Game.step`이
  고정 스텝마다 부른다(오프라인·호스트는 `raceManager.raceTime`, 온라인 클라이언트는 호스트 시계).
  같은 시각이면 모든 클라이언트에서 같은 자리다.
- 움직이는 장애물은 `track.obstacles`에 들어간다(위치가 매 스텝 바뀐다). 카트 충돌과 AI 회피가 이
  배열을 이미 본다. `TrackObstacle`에 선택 필드 `velocity`, `hit`을 추가한다.
  - `hit: true`인 장애물에 부딪히면 스핀한다(`applyHit('collision')`). 스타 중에는 튕기기만 한다.
  - AI는 `velocity`로 도착 시점의 위치를 예측해 피하고, 길이 막히면 속도를 줄인다.
- 종류: `roller`(주로를 따라 굴러오는 바위·눈덩이·용암 덩이), `crosser`(주기적으로 도로를 가로지르는
  트램·수레, 여러 량).

### 2.4 지름길

- `wallHalfWidthFactors`로 일부 구간의 벽을 멀리 민다. S자 구간을 직선으로 가로지르면 짧지만 오프로드라
  니트로·스타가 있어야 이득이다(기존 오프로드 규칙 그대로).
- 헤어핀을 가로지르는 점프 지름길은 하지 않는다(중심선 하나짜리 모델에서 주로 판정이 깨진다).

## 4. 컵, 오늘의 도전, 서버

- 컵: `rookie`(3)·`pro`(3)는 그대로. 새 컵 `stunt`(windmill_way, tidal_run, stunt_park, tram_town,
  `rookie` 필요), `extreme`(canyon_rally, glacier_gap, ashfall_run, skyline_loop, `pro` 필요).
  `championship`은 **기존 8개 그대로** 둔다. 원래 주석은 "서킷이 늘면 같이 늘어난다"였지만 16연전은
  한 번에 하기에 너무 길고 중간 저장이 없다. 테스트를 "모든 서킷이 어느 컵에든 들어 있다"로 바꾼다.
- `server.js`: `TRACKS`에 8개, `CUPS`에 `stunt`·`extreme` 추가.
- 오늘의 도전은 클라이언트가 `tracks[seed % tracks.length]`로 고르고 서버는 날짜만 본다. 서킷 수가 바뀌면
  모든 날짜의 서킷이 바뀐다. 배포하는 날 UTC 하루 동안은 구버전과 신버전이 다른 서킷으로 같은 순위표에
  올라갈 수 있다(보고만 한다).

## 7. 구현 중 판단 (2026-11-18)

스펙과 달라졌거나, 스펙이 정하지 않아 구현하면서 정한 것들.

- **새 서킷 레이아웃은 직선과 원호의 조합으로 만들었다.** 직선 길이와 90°/180° 원호만으로 한 바퀴를
  구성하면 계산상 반드시 닫히고, 기믹 위치(t)도 구간 길이에서 바로 나온다. 그 결과 새 서킷은 기존
  서킷보다 각이 진 편이다. 생성 스크립트는 저장소에 넣지 않았다. `src/track/tracks/*.ts`가 원본이다.
- **지름길은 "벽을 뒤로 물린 구간"으로만 구현했다.** 중심선이 하나라 갈림길은 만들 수 없다.
  Windmill Way의 시케인과 Canyon Rally의 지그재그는 벽이 멀어서 오프로드를 가로지를 수 있고,
  부스트가 있을 때만 이득이다. Switchback Pass의 헤어핀 관통 지름길, 옆바람, 8자 교차(Crossover)는
  넣지 않았다(1~3절의 범위 밖 결정 그대로).
- **움직이는 장애물 두 개를 서로 다른 차선에 두지 않는다.** AI가 하나를 피하면서 다른 하나의 차선으로
  들어가 레이스당 10회 넘게 부딪혔다(Magma Ridge, Glacier Gap에서 확인). 한 구간의 굴러오는 장애물은
  같은 쪽 차선에 두고 반 주기 어긋나게 했다. 또 코너 진입 직전에는 AI가 안쪽으로 붙으므로 장애물은
  그 반대쪽 차선에 둔다(Glacier Gap 뒷직선). 이렇게 해서 레이스당 0~6회.
- **Ashfall Run의 조명은 스펙의 "화산재 구름"보다 밝게 했다.** 처음 값으로는 노면이 거의 검게 보여
  끊긴 다리의 점프대가 잘 안 보였다.
- **선택 화면(5절)**: "폰 가로 한 줄 8장"이 아니라 레이서 6열 3줄(844×390, 932×430에서 스크롤 없음),
  서킷은 4열 스크롤이다. 8열은 카드 폭이 100px 아래로 내려가 이름이 잘린다. PC는 레이서·서킷 모두
  4×4이고, 격자가 남는 높이를 네 줄이 나눠 가져 1000×700 이상에서는 스크롤이 없다. 체급 칩과 랩 수는
  썸네일 위로 올렸다(카드가 두 줄).
- **컵에 커서를 올리면 그 컵에 없는 서킷이 어두워진다.** 컵 5개·서킷 16개가 되면서 컵 이름만으로는
  무엇을 달리는지 알 수 없어서 추가했다. 터치에서는 잠긴 컵을 눌렀을 때 같은 표시가 나온다.
- **기록 패널·온라인 방의 서킷 고르기**는 포인터가 있으면 4×4 격자, 터치에서는 옆으로 미는 한 줄이다.
- **키보드**: 서킷 격자 안에서 위/아래가 카드 줄을 따라 움직이고, 맨 아래 줄에서 아래를 누르면 옵션
  줄로 내려간다. 패널이 스크롤될 때는 커서 카드가 아래 고정 띠에 가리지 않게 스크롤한다.
- **팁 4개 추가**(얼음, 진흙·물, 전차·바위, 끊긴 다리), 팁 10번은 "점프 정상에서 홉"에서 공중 묘기
  설명으로 바꿨다.
