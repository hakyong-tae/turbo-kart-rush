## 2. 현재 빌드 점검에서 나온 사실 (`9958152`, 새 저장 상태, 영어, Sunny Circuit)

- 첫 접속에 출석 창이 뜨고, 두 판 뒤 코인 300·레벨 2·미션 2/3이 된다. 이 부분은 동작한다.

  카트를 대신 몰아도 보통 난이도에서 3회 중 1회 리타이어(+5코인), 1회 8위였다.

- 서킷 16개가 처음부터 전부 열려 있다. 플레이로 열리는 것은 컵뿐이다. 첫 획득 전용 아이템은
  레벨 5(경험치 700)다.
- 출석 2일차 보상은 60코인이다. "At 7 days: Sun"은 뜻을 알기 어렵다.
- 터치: 자동 가속이 없고, 스틱은 누르기 전에는 보이지 않으며, 조작 안내는 첫 로딩 화면에만 나온다.
  세로 화면은 회전 안내 창이 게임을 가린다.
- Verse8 밖에서도 "UNLOCK GARAGE · 100 VX"와 "WATCH AD" 버튼이 보이고, 광고는 모의 창이 뜬다.
  CrazyGames용 빌드 타깃이 없다.
- 점검 스크립트: 이 폴더의 `first-session.mjs` (AI가 플레이어를 대신 몰되 보상은 받는 주행).
  캡처: `first-session-audit/`.

## 3. Crazy Kart에서 가져올 것

CrazyGames의 Crazy Kart(GKG, 2026-10, 평점 8.1)를 직접 플레이해서 본 것이다. 3분짜리 배틀 아레나라
장르는 다르다. **구조와 흐름만 가져오고, 이름·캐릭터·그림·아레나·문구는 가져오지 않는다.**
그쪽의 실제 지표는 알 수 없고, 결과 화면은 보지 못했다.

| 관찰 | 우리 게임에 적용 |
|---|---|
| 게임이 뜨면 메뉴 없이 바로 경기 안이다 | 4.1 첫 접속 즉시 레이스 |
| 첫 경기 안에서 6단계 "해 보며 배우기" 카드(누를 키, 진행 바, 건너뛰기). 끝날 때까지 경기 시계가 멈춰 있다 | 4.1 첫 레이스 안내 |
| HUD에 키 안내가 항상 붙어 있다(부스트 키, 드리프트 키, 빈 아이템 칸의 "? 상자를 먹으세요") | 4.6 HUD 안내 |
| "LONG DRIFT +12", "RICOCHET +2" 같은 짧은 보상 문구가 계속 뜬다 | 4.6 이벤트 피드 |
| 차고에 화폐가 없다. 항목마다 조건과 진행도가 적혀 있다(1판 완주, 1승, 3판 완주, 5판 완주, 묘기 10회) | 4.3 초반 해금 사다리 |
| 메인 메뉴 버튼이 4개(큰 시작 버튼 + 3개)다 | 4.7 로비 단순화 |
| "이 기기에 자동 저장" 문구가 차고에 있다 | 4.7 |
| 경기 길이가 3분으로 고정이고 마지막 30초에 점수 2배 | 4.2 마지막 랩 연출 |
| 스토어: 태그 6개(Action, Mobile, 3D, Arena, Car, Cartoon), 방향 Landscape 선언, 소개 첫 줄이 한 문장 훅 | 4.8 제출 자료 |

## 4. 바꿀 것

### 4.1 첫 접속 즉시 레이스 (전환, 플레이타임)

- 저장 기록이 없는 첫 접속은 로비를 건너뛰고 Sunny Circuit, 기본 카트, 솔로로 바로 레이스에 들어간다.
  출석 창은 처음 로비에 돌아왔을 때 띄운다.
- 첫 레이스에는 안내 카드가 뜬다: 가속 → 조향 → 드리프트로 부스트 → 아이템 사용. 해당 조작을 하면
  다음 단계로 넘어가고, "건너뛰기"가 있다. 카운트다운은 첫 단계(가속)를 마칠 때 시작한다.
  터치와 키보드에서 각각 맞는 그림·문구를 쓴다.
- 첫 3판은 입문 난이도다: AI 속도와 아이템 공격을 낮춰, 완주만 해도 대체로 3위 안에 든다.
  3판 뒤에는 고른 난이도로 돌아간다. 입문 난이도 판은 기록 순위에 올리지 않는다.
- 플레이어는 전진하고 있는 한 리타이어되지 않는다. 플레이어의 제한을 우승자 +30초로 늘리고,
  AI는 10초 그대로 둔다. 온라인 레이스 규칙은 바꾸지 않는다.

### 4.2 결과 화면이 다음 판으로 이끈다 (플레이타임)

- 주 버튼을 "다음 레이스"로 바꾼다. 쉬운 순서로 다음 서킷에 간다(4.3에서 방금 열린 서킷이 있으면
  그 서킷). "다시 레이스"와 "서킷 변경", "로비"는 보조 버튼으로 남긴다. 컵 진행 중에는 지금처럼 컵의
  다음 경기다.
- 보상 영역을 키우고 순위표 위로 올린다: 코인 카운트업, 경험치 바, 레벨업.
- "다음 해금" 줄을 넣는다: 가장 가까운 사다리 목표 하나와 진행 바(예: "레이스 3회 완주 2/3 → 무지개
  트레일"). 방금 열린 것이 있으면 "새로 열림" 카드로 먼저 보여 준다.
- 폰에서는 순위표를 상위 3명 + 나로 줄여 보상과 버튼이 스크롤 없이 보이게 한다.
- 마지막 랩: "FINAL LAP" 배너, 아이템 상자 추가 배치, 음악 고조. 이미 있는 것은 그대로 둔다.

### 4.3 초반 해금 사다리 (플레이타임, D1)

코인과 별개로, 조건을 채우면 바로 열리는 무료 해금을 둔다. 첫 3판은 매 판 하나씩 열리게 한다.

| 조건 | 열리는 것 |
|---|---|
| 레이스 1회 완주 | 서킷 +1, 라이버리 1종 |
| 레이스 2회 완주 | 서킷 +1, 휠 효과 1종 |
| 레이스 3회 완주 | 서킷 +1, 트레일 1종 |
| 3위 안 1회 | 언더글로우 1종 |
| 드리프트 부스트 10회 | 배기 화염 1종 |
| 레이스 5회 완주 | 엠블럼 1종 + 루키 컵 안내 |
| 1등 1회 | 스페셜 라이버리 1종 |
| 이후 완주 1회마다 | 서킷 +1 (16개가 다 열릴 때까지) |

- 새 저장은 서킷 4개(별 1개짜리)로 시작하고 완주할 때마다 쉬운 순서로 하나씩 열린다.
  **기존 저장(레이스 기록이나 코인이 있는 유저)은 16개가 전부 열린 상태로 둔다.**
  컵과 오늘의 도전, 온라인 방은 잠긴 서킷도 쓸 수 있다.
- 열리는 외형은 기존 카탈로그에서 고른다(배열 순서는 바꾸지 않는다). 사다리로 받은 항목은 코인으로
  살 필요가 없다. 100VX 패스 보유자는 이미 가진 것이므로 사다리 표시는 "획득함"이다.
- 차고 카드에 조건과 진행도를 적는다("레이스 3회 완주 · 2/3"). 서킷 선택의 잠긴 카드에도 조건을 적는다.
- 서버 계산 원칙은 그대로다: `server.js`가 판정하고, `core/economy.ts`에 같은 표를 두고,
  `serverEconomy.test.ts`가 둘을 맞춘다.

### 4.4 내일 올 이유 (D1)

- 출석 2일차 보상을 코인 + 눈에 보이는 외형 1종으로 바꾼다. 출석 창의 "At 7 days: Sun"은 아이템
  그림과 이름으로 바꾼다("7일차: 태양 엠블럼").
- 그날 두 번째 판의 결과 화면과, 결과에서 로비로 나올 때 "내일 보상" 카드를 한 번 보여 준다:
  내일 받을 외형 그림, 교체까지 남은 시간.
- 가입 첫날의 일일 미션은 3판 안에 끝나는 고정 조합이다: 레이스 3회 완주, 아이템 8개 사용,
  드리프트 부스트 10회. 둘째 날부터는 지금의 날짜 시드 방식이다.

### 4.5 모바일 (전환)

- 터치에서는 자동 가속이 기본이다. 스틱을 아래로 당기면 브레이크·후진이다. 설정에서 끌 수 있다.
- 스틱은 기본 위치에 항상 반투명으로 보인다.
- 세로 화면: 회전 안내 창은 유지하되, CrazyGames 제출에서 방향을 Landscape로 선언한다(4.8).
- 폰 결과 화면은 4.2대로 한 화면에 들어온다.

### 4.6 HUD 안내와 피드백

- 첫 3판 동안 HUD에 조작 안내를 붙인다: 빈 아이템 칸 "? 상자를 먹으세요", 아이템 보유 시 사용 키,
  코너 진입 시 드리프트 키. 4판째부터는 사라진다.
- 이벤트 피드: "드리프트 부스트!", "추월!", "명중!", "슬립스트림!"을 짧게 띄운다. 미션 진행도가
  오르면 같은 자리에 "아이템 5/8"처럼 띄운다. 코인 규칙은 바꾸지 않는다(문구만).

### 4.7 로비 단순화

- 큰 "레이스" 버튼 하나 + 차고 + 미션. 출석, 오늘의 도전, 기록, 설정은 작은 아이콘 줄로 내린다.
  기존 클래스 이름(`.single-toggle` 등)은 도구가 쓰므로 유지한다.
- 차고에 "이 기기에 자동 저장됩니다" 문구를 넣는다(Verse8 호스트 밖에서만).

### 4.8 CrazyGames 빌드와 이름

- 새 이름은 **Drift Kart**다. 브랜드를 빌드 설정으로 뺀다: CrazyGames 빌드는 "Drift Kart"
  (워드마크 "DRIFT" + 노란 번호판 "KART", 문서 제목, 한·영 문구), Verse8·원스토어 빌드는
  "Drift Dash GP" 그대로다.
- CrazyGames 타깃(예: `vite build --mode crazygames`, 출력 `dist-crazygames/`):
  - VX 결제 UI와 프리미엄 패스 문구를 숨긴다. 프리미엄 카트는 코인 해금만 보인다.
  - 보상형 광고 버튼(코인 2배, 미션 교체, 광고로 연속 접속 복구)을 숨긴다. Basic Launch 동안은
    광고가 꺼져 있다. 연속 접속이 하루 끊겼을 때는 광고 없이 1회 무료 복구로 둔다.
  - 온라인 패널을 숨긴다. 저장은 `localServer.ts`(브라우저 저장소)를 쓴다.
  - 빌드 크기 20MB 미만, 첫 화면까지 10초 미만을 확인한다.
- 제출 자료 초안을 `marketing/crazygames/`에 만든다: 한 문장 훅으로 시작하는 영어 소개,
  조작법(지금 빌드 기준, 카트 16·서킷 16), 태그 제안, 방향 Landscape, 썸네일·미리보기 영상 요구 사항.
  썸네일과 영상 제작, 포털 제출은 이 작업에 포함하지 않는다.

## 5. 하지 않는 것

- 배틀 모드, 그림 스타일 변경, UI "서킷 포스터" 재개편.
- push, Verse8 배포, CrazyGames 포털 제출. 전부 로컬에서 끝낸다.
- `package-lock.json`의 기존 변경은 건드리지 않는다. `verse8` 원격 주소의 토큰은 출력하지 않는다.

## 6. 검증

- `npm run typecheck`, `npm test`, `npm run build`, CrazyGames 타깃 빌드가 통과한다.
- `first-session.mjs`를 새 저장 상태로 돌려 확인한다(PC 1280×720, 폰 844×390, 한·영):
  - 클릭 없이 첫 레이스에 들어간다.
  - 첫 3판에서 플레이어가 리타이어되지 않는다.
  - 판마다 "새로 열림"이 하나 이상 나온다.
  - 결과 화면의 주 버튼이 다음 서킷으로 간다.
  - 폰 결과 화면이 스크롤 없이 보인다.
  - CrazyGames 빌드에 "VX", "WATCH AD", "Drift Dash" 문구가 없다.
- 기존 저장(코인·레이스 기록 있음)으로 열었을 때 서킷 16개가 전부 열려 있다.
- 브라우저 검증은 헤드리스 + 음소거.

## 7. 구현 중 판단 (2026-11-20, 브랜치 `crazygames-relaunch`)

명세가 코드와 맞지 않거나 정하지 않은 곳에서 구현하면서 정한 것들이다.

### 해금 사다리 (4.3)

- **시작 서킷 4개**: 별 1개짜리 서킷은 3개뿐이다(Sunny Circuit, Windmill Way, Tidal Run). 네 번째는 쉬운
  순서의 다음인 Coral Coast(별 2개)로 했다. 열리는 순서는 서킷 선택 화면의 순서와 같다
  (`TRACKS_BY_DIFFICULTY`, 서버의 `TRACK_ORDER`).
- **사다리 항목**: 전부 기존 유료 항목에서 골랐다. 완주 1회 체커 라이버리, 2회 스포크 글로우 휠 효과,
  3회 스파크 트레일, 3위 안 솔리드 언더글로우, 드리프트 부스트 10회 제트 배기 화염, 5회 볼트 엠블럼,
  1등 스타필드 라이버리. 코인으로 먼저 살 수도 있고, 패스 보유자는 이미 가진 것이라 차고에 "획득함"으로
  나오며 결과 화면에 "새로 열림"으로 알리지 않는다.
- **기존 저장 판정**: 유저 상태에 사다리 기록(`lad`)이 없고, 다른 키(코인·경험치·닉네임·외형·컵·광고권 등)가
  하나라도 있거나 기록 순위(`tkr_times`)에 그 계정의 기록이 있으면 기존 계정으로 보고 16개를 전부 연다.
  이 판정은 계정당 한 번이며 `getMyEntitlements`·`beginRace`·`claimAttendance`가 처음 불릴 때 기록한다.
  기존 계정도 사다리의 외형은 플레이하면서 받는다(완주 횟수는 이번 빌드부터 센다).
- **서킷 잠금은 선택 화면에서만 막는다.** 서버는 열린 개수를 계산해 알려 줄 뿐, `beginRace`는 잠긴
  서킷도 받는다. 컵과 오늘의 도전이 잠긴 서킷을 쓰기 때문이다.
- **드리프트 부스트 횟수**는 기존 미션과 같은 카운터다: 2단계 이상의 미니 터보만 센다.

### 입문 난이도와 리타이어 (4.1)

- 입문 판은 **서버가 정한다**: 새 계정의 정산된 레이스가 3판 미만이고 일반 레이스일 때. 컵·오늘의 도전·
  온라인은 입문 판이 아니지만 3판에는 들어간다. `?auto`나 `?b.` 주행에는 적용하지 않는다.
- 입문 판은 고른 난이도와 관계없이 **'보통' 배율로 지급**한다. 상대가 고른 난이도가 아니기 때문이다.
- 입문 AI(`BALANCE.ai.intro`): 최고 속도의 60~79%로 달린다(플레이어보다 앞서면 느려지고 뒤처지면
  빨라진다). 아이템은 니트로와 바나나만 나온다. 출발 때 가속을 끝까지 누르고 있어도 엔진이 꺼지지
  않는다(안내 카드가 누르라고 하므로). 기록 순위와 이 기기의 최고 기록에 올리지 않는다.
- 리타이어: 플레이어보다 **뒤에 있는** AI는 지금처럼 우승자 +10초에 리타이어되고, 앞에 있는 AI는 계속
  달린다. 플레이어는 +30초까지, 그 뒤에도 전진 중이면(5초 동안 랩의 0.4% 이상) 계속 달리며 +75초가
  상한이다. 리타이어 순위는 뒤에서부터 매긴다: 먼저 리타이어된 카트가 나중에 완주한 카트보다 위에 오지
  않게 하려면 필요했다.

### 첫 접속 (4.1)

- "저장 기록이 없는 첫 접속"은 이 기기에 표시(`tkr.firstRace`)가 없고, 서버가 새 계정(레이스 0판)이라고
  답할 때다. 서버 응답을 3초까지 기다리며 그동안 로비 버튼을 숨긴다. 응답이 없으면 로비를 보여 주고
  다음 접속에 다시 판단한다. `?auto`와 `?lobby`는 예외다(도구용).
- 안내 카드의 첫 단계는 키보드에서는 가속 키, 터치에서는 화면 아무 곳이나 누르면 끝난다(터치는 자동
  가속이라 누를 가속이 없다). 8초 동안 아무 입력이 없으면 스스로 출발한다.
- 안내는 기기당 한 번이다. 드리프트·아이템 단계를 끝내지 못해도 그 판이 끝나면 다시 나오지 않는다.

### 결과 화면과 내일 보상 (4.2, 4.4)

- 화면이 넓으면(760px 이상) 두 칸이다: 왼쪽에 순위 번호판·보상·새로 열림·다음 해금, 오른쪽에 순위표.
  좁으면 한 칸이며 보상이 순위표 위다.
- "다음 해금"은 아직 받지 않은 사다리 단계 중 진행률이 가장 높은 것, 사다리가 끝나면 다음 서킷,
  그다음은 다음 레벨 보상이다. 출석 단계는 "내일 보상"에서 다루므로 여기서는 뺐다.
- "내일 보상"은 그날 두 번째 판의 결과 화면 안에 넣었다. 로비로 나올 때는 별도 창을 만들지 않고 출석
  창을 쓴다: 오늘 출석을 아직 안 했으면 원래 출석 창이 뜨고 받은 뒤 내일 보상이 보이며, 이미 했으면
  하루 한 번 출석 창이 내일 보상을 보인 채로 뜬다.
- 출석 2일차 외형은 레인보우 언더글로우다. 누적 출석 일수 기준이라 사다리 표의 한 단으로 넣었다.
- 마지막 랩의 아이템 상자: 상자 줄 사이가 가장 넓은 곳 한가운데에 3개짜리 한 줄을 연다(일반 노면이고
  점프대 진입 구간이 아닌 곳). 오프라인 레이스만.
- 5회 완주 때의 "루키 컵 안내"는 결과 화면의 알림 한 줄이다.
- **"새로 열림" 카드의 이름은 자르지 않는다(후속 수정).** 처음에는 한 줄 + 말줄임이라 긴 이름이 잘리고
  ("SOLID UNDERGLO…"), 딱 맞는 이름도 기울임꼴 마지막 글자가 깎였다("DUNE DRIF"). 지금은 카드 폭은 그대로
  두고 긴 이름이 두 줄로 고르게 나뉘며, 카드가 그만큼 커진다. 가장 긴 이름("Spoke Glow wheel effect",
  "스포크 글로우 휠 효과")도 PC·폰에서 두 줄 안에 들어온다. `tools/unlock-card-check.mjs`가 사다리 8종과
  서킷 16개 이름을 전부 넣어 잰다.

### HUD 피드 (4.6, 후속 수정)

- 이벤트 피드는 아래쪽 끝을 고정하고 위로 쌓는다(새 줄이 맨 아래). 처음에는 위에서 아래로 쌓여서 둘째
  줄부터 화면 가운데의 순위 번쩍임과 겹쳤다. 추월하면 "추월!" 줄과 순위 번쩍임이 같이 뜨기 때문에 자주
  보였다. 폰에서 먼저 보였지만 PC도 세 줄이면 겹쳐서 같이 고쳤다. 폰은 두 줄까지만 보인다(셋째 줄은 랩
  배너 자리에 닿는다). `tools/hud-feed-check.mjs`가 프레임마다 겹침을 잰다.

### 터치 (4.5)

- 자동 가속은 레이스 중에만 켜진다. 카운트다운 동안은 켜지 않아서 로켓 스타트는 지금처럼 스틱을 위로
  밀어 직접 맞춘다. 마지막으로 쓴 입력이 키보드면(터치 겸용 노트북) 자동 가속을 하지 않는다.
- 스틱을 누르면 손가락 위치로 옮겨 오고 떼면 기본 위치로 돌아간다. 고치면서 보니 기존에는 스틱이
  손가락보다 화면 높이의 18% 아래에 그려지고 있어서 같이 고쳤다.

### CrazyGames 빌드 (4.8)

- 빌드에서 Verse8 SDK 세 개를 빼고 대역(`src/verse8/stubs/sdk.ts`)을 넣었다. 문구 테이블에서 VX·광고·
  Verse8을 말하는 줄을 빌드할 때 지우고, 브라우저 안에서 도는 `server.js`는 주석 없이 싣는다. 그래서

- "광고 없이 1회 무료 복구"는 하루 끊길 때마다 한 번 무료로 이어 갈 수 있다는 뜻으로 구현했다(끊긴 지
  이틀 이상이면 지금처럼 1일차부터다).
- 프리미엄 카트의 잠금 창에는 코인 해금과 "다른 카트 고르기"만 남는다. 광고 3회권은 이 빌드에 없다.
- 로고 아래 부제 "ARCADE GRAND PRIX"는 그대로 뒀다.
- **CrazyGames SDK는 연동하지 않았다.** 명세에 없고 Basic Launch의 요건도 아니다. Full Launch 전에 할
  일은 `marketing/crazygames/SUBMISSION.md`에 적었다.
- **글꼴은 빌드에 싣는다(후속 수정).** 처음에는 Google Fonts에서 받았는데(외부 요청 2곳), 포털 검수에
  걸릴 수 있어 CrazyGames 빌드는 자기 출처 밖으로 나가는 요청이 0건이 되게 했다. `src/assets/fonts/`에
  세 글꼴을 넣고(`tools/subset-fonts.py`가 만든다, 모두 OFL), 빌드가 `index.html`의 Google 링크를
  `src/styles/fonts-local.css`로 바꾼다. npm 의존성은 늘지 않았다.
  - Anton(영문 제목): 통째로 52KB. Impact가 없는 기기에서만 받는다.
  - Black Han Sans(한글 제목): 게임에 나오는 한글 508자와 자모만 추려 45KB. 한글이 화면에 있을 때만 받는다.
  - Noto Sans KR(한글 본문): 같은 한글 + 라틴·기호, 굵기 400~900 가변 글꼴 하나로 123KB. 한국어일 때만 받는다.
  - 한글을 시스템 글꼴로 넘기지 않은 이유: 기기마다 모양이 달라지고(애플 SD 산돌고딕, 맑은 고딕),
    168KB로 Verse8판과 같은 모양을 유지할 수 있어서다. 영어로 하는 사람은 한글 글꼴을 받지 않는다.
  - 추린 글자 밖의 한글(직접 입력한 닉네임)은 그 글자만 시스템 글꼴로 그려진다. 한국어 문구를 추가하면
    글꼴을 다시 만들어야 하고, 잊으면 `src/assets/fonts/charset.test.ts`가 실패한다.
  - **기본(Verse8·원스토어) 빌드는 그대로 Google Fonts를 쓴다.** 모양이 달라지면 안 되고, 리더보드에 다른
    사람의 닉네임(아무 한글이나)이 나오는 판이라 추린 글꼴이 맞지 않는다. 기본 빌드 산출물에는 글꼴 파일이
    들어가지 않는다.

### 확인하지 못한 것

- 실제 폰·태블릿에서 싣은 글꼴이 그려지는 모습(헤드리스 Chrome에서 읽히는 것만 확인했다). Impact가 없는
  기기에서 Anton이 쓰이는 경로는 글꼴을 직접 불러 확인했고, 화면 캡처는 Impact가 있는 맥에서 찍었다.
- 해금 카드에 실제 그림(서킷 썸네일, 카트)이 들어간 상태의 전수 측정. 점검 도구는 그림 자리에 아이콘을
  넣는다(그림 칸의 폭은 같다). 실제 그림이 들어간 화면은 first-session 캡처 12장으로 봤다.

- **입문 난이도의 실제 체감.** 위 순위는 쉬움 AI가 몬 결과다(12판 중 9판이 3위 안, 최저 5위). 처음 하는
  사람이 몰았을 때의 순위는 재지 못했다.
- **Verse8 호스트 안의 동작 전부.** 서버 함수는 브라우저 안의 `server.js`와 테스트로만 확인했다. 실제
  유저 상태에서 기존 계정 판정이 맞는지, 새 계정이 4개로 시작하는지는 배포 뒤에 봐야 한다.
- **실기기 터치.** 자동 가속과 스틱은 헤드리스 화면에서 표시와 동작만 확인했다.
- **CrazyGames 포털의 검수.** SDK 미연동이 Basic Launch에서 문제가 되는지는 포털에 올려 봐야 안다(외부
  요청은 후속 수정으로 0건이 됐다).
- 폭 760px 미만의 한 칸 결과 화면, 세로 화면, 게임패드는 이번에 캡처로 확인하지 않았다.
- 안내 카드의 드리프트·아이템 단계는 AI가 몬 주행에서만 지나갔다(사람 입력으로는 가속·조향 단계까지
  확인했다).
- 썸네일과 미리보기 영상은 만들지 않았다.
