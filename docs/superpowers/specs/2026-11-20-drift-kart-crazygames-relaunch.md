## 2. 현재 빌드 점검에서 나온 사실 (`9958152`, 새 저장 상태, 영어, Sunny Circuit)

- 첫 접속에 출석 창이 뜨고, 두 판 뒤 코인 300·레벨 2·미션 2/3이 된다. 이 부분은 동작한다.
- 로비 → 레이스 시작: 클릭 3번, 6.4초. "다시 레이스": 3.5초.
- 우승자가 들어온 뒤 10초(`balance.ts` `retireSeconds: 10`)가 지나면 리타이어다. 하드 AI가 플레이어
  카트를 대신 몰아도 보통 난이도에서 3회 중 1회 리타이어(+5코인), 1회 8위였다.
- 결과 화면: 보상 줄이 맨 아래에 작게 있고, 코인의 쓸모와 다음 해금이 안 보인다. "다시 레이스"는
  같은 서킷을 반복한다. 폰에서는 순위표가 5위에서 잘린다.
- 서킷 16개가 처음부터 전부 열려 있다. 플레이로 열리는 것은 컵뿐이다. 첫 획득 전용 아이템은
  레벨 5(경험치 700)다.
- 출석 2일차 보상은 60코인이다. "At 7 days: Sun"은 뜻을 알기 어렵다.
- 터치: 자동 가속이 없고, 스틱은 누르기 전에는 보이지 않으며, 조작 안내는 첫 로딩 화면에만 나온다.
  세로 화면은 회전 안내 창이 게임을 가린다.
- Verse8 밖에서도 "UNLOCK GARAGE · 100 VX"와 "WATCH AD" 버튼이 보이고, 광고는 모의 창이 뜬다.
  CrazyGames용 빌드 타깃이 없다.
- 점검 스크립트: 이 폴더의 `first-session.mjs` (AI가 플레이어를 대신 몰되 보상은 받는 주행).
  캡처: `first-session-audit/`.

## 3. Crazy Kart에서 가져올 것

CrazyGames의 Crazy Kart(GKG, 2026-10, 평점 8.1)를 직접 플레이해서 본 것이다. 3분짜리 배틀 아레나라
장르는 다르다. **구조와 흐름만 가져오고, 이름·캐릭터·그림·아레나·문구는 가져오지 않는다.**
그쪽의 실제 지표는 알 수 없고, 결과 화면은 보지 못했다.

| 관찰 | 우리 게임에 적용 |
|---|---|
| 게임이 뜨면 메뉴 없이 바로 경기 안이다 | 4.1 첫 접속 즉시 레이스 |
| 첫 경기 안에서 6단계 "해 보며 배우기" 카드(누를 키, 진행 바, 건너뛰기). 끝날 때까지 경기 시계가 멈춰 있다 | 4.1 첫 레이스 안내 |
| HUD에 키 안내가 항상 붙어 있다(부스트 키, 드리프트 키, 빈 아이템 칸의 "? 상자를 먹으세요") | 4.6 HUD 안내 |
| "LONG DRIFT +12", "RICOCHET +2" 같은 짧은 보상 문구가 계속 뜬다 | 4.6 이벤트 피드 |
| 차고에 화폐가 없다. 항목마다 조건과 진행도가 적혀 있다(1판 완주, 1승, 3판 완주, 5판 완주, 묘기 10회) | 4.3 초반 해금 사다리 |
| 메인 메뉴 버튼이 4개(큰 시작 버튼 + 3개)다 | 4.7 로비 단순화 |
| "이 기기에 자동 저장" 문구가 차고에 있다 | 4.7 |
| 경기 길이가 3분으로 고정이고 마지막 30초에 점수 2배 | 4.2 마지막 랩 연출 |
| 스토어: 태그 6개(Action, Mobile, 3D, Arena, Car, Cartoon), 방향 Landscape 선언, 소개 첫 줄이 한 문장 훅 | 4.8 제출 자료 |

## 4. 바꿀 것

### 4.1 첫 접속 즉시 레이스 (전환, 플레이타임)

- 저장 기록이 없는 첫 접속은 로비를 건너뛰고 Sunny Circuit, 기본 카트, 솔로로 바로 레이스에 들어간다.
  출석 창은 처음 로비에 돌아왔을 때 띄운다.
- 첫 레이스에는 안내 카드가 뜬다: 가속 → 조향 → 드리프트로 부스트 → 아이템 사용. 해당 조작을 하면
  다음 단계로 넘어가고, "건너뛰기"가 있다. 카운트다운은 첫 단계(가속)를 마칠 때 시작한다.
  터치와 키보드에서 각각 맞는 그림·문구를 쓴다.
- 첫 3판은 입문 난이도다: AI 속도와 아이템 공격을 낮춰, 완주만 해도 대체로 3위 안에 든다.
  3판 뒤에는 고른 난이도로 돌아간다. 입문 난이도 판은 기록 순위에 올리지 않는다.
- 플레이어는 전진하고 있는 한 리타이어되지 않는다. 플레이어의 제한을 우승자 +30초로 늘리고,
  AI는 10초 그대로 둔다. 온라인 레이스 규칙은 바꾸지 않는다.

### 4.2 결과 화면이 다음 판으로 이끈다 (플레이타임)

- 주 버튼을 "다음 레이스"로 바꾼다. 쉬운 순서로 다음 서킷에 간다(4.3에서 방금 열린 서킷이 있으면
  그 서킷). "다시 레이스"와 "서킷 변경", "로비"는 보조 버튼으로 남긴다. 컵 진행 중에는 지금처럼 컵의
  다음 경기다.
- 보상 영역을 키우고 순위표 위로 올린다: 코인 카운트업, 경험치 바, 레벨업.
- "다음 해금" 줄을 넣는다: 가장 가까운 사다리 목표 하나와 진행 바(예: "레이스 3회 완주 2/3 → 무지개
  트레일"). 방금 열린 것이 있으면 "새로 열림" 카드로 먼저 보여 준다.
- 폰에서는 순위표를 상위 3명 + 나로 줄여 보상과 버튼이 스크롤 없이 보이게 한다.
- 마지막 랩: "FINAL LAP" 배너, 아이템 상자 추가 배치, 음악 고조. 이미 있는 것은 그대로 둔다.

### 4.3 초반 해금 사다리 (플레이타임, D1)

코인과 별개로, 조건을 채우면 바로 열리는 무료 해금을 둔다. 첫 3판은 매 판 하나씩 열리게 한다.

| 조건 | 열리는 것 |
|---|---|
| 레이스 1회 완주 | 서킷 +1, 라이버리 1종 |
| 레이스 2회 완주 | 서킷 +1, 휠 효과 1종 |
| 레이스 3회 완주 | 서킷 +1, 트레일 1종 |
| 3위 안 1회 | 언더글로우 1종 |
| 드리프트 부스트 10회 | 배기 화염 1종 |
| 레이스 5회 완주 | 엠블럼 1종 + 루키 컵 안내 |
| 1등 1회 | 스페셜 라이버리 1종 |
| 이후 완주 1회마다 | 서킷 +1 (16개가 다 열릴 때까지) |

- 새 저장은 서킷 4개(별 1개짜리)로 시작하고 완주할 때마다 쉬운 순서로 하나씩 열린다.
  **기존 저장(레이스 기록이나 코인이 있는 유저)은 16개가 전부 열린 상태로 둔다.**
  컵과 오늘의 도전, 온라인 방은 잠긴 서킷도 쓸 수 있다.
- 열리는 외형은 기존 카탈로그에서 고른다(배열 순서는 바꾸지 않는다). 사다리로 받은 항목은 코인으로
  살 필요가 없다. 100VX 패스 보유자는 이미 가진 것이므로 사다리 표시는 "획득함"이다.
- 차고 카드에 조건과 진행도를 적는다("레이스 3회 완주 · 2/3"). 서킷 선택의 잠긴 카드에도 조건을 적는다.
- 서버 계산 원칙은 그대로다: `server.js`가 판정하고, `core/economy.ts`에 같은 표를 두고,
  `serverEconomy.test.ts`가 둘을 맞춘다.

### 4.4 내일 올 이유 (D1)

- 출석 2일차 보상을 코인 + 눈에 보이는 외형 1종으로 바꾼다. 출석 창의 "At 7 days: Sun"은 아이템
  그림과 이름으로 바꾼다("7일차: 태양 엠블럼").
- 그날 두 번째 판의 결과 화면과, 결과에서 로비로 나올 때 "내일 보상" 카드를 한 번 보여 준다:
  내일 받을 외형 그림, 교체까지 남은 시간.
- 가입 첫날의 일일 미션은 3판 안에 끝나는 고정 조합이다: 레이스 3회 완주, 아이템 8개 사용,
  드리프트 부스트 10회. 둘째 날부터는 지금의 날짜 시드 방식이다.

### 4.5 모바일 (전환)

- 터치에서는 자동 가속이 기본이다. 스틱을 아래로 당기면 브레이크·후진이다. 설정에서 끌 수 있다.
- 스틱은 기본 위치에 항상 반투명으로 보인다.
- 세로 화면: 회전 안내 창은 유지하되, CrazyGames 제출에서 방향을 Landscape로 선언한다(4.8).
- 폰 결과 화면은 4.2대로 한 화면에 들어온다.

### 4.6 HUD 안내와 피드백

- 첫 3판 동안 HUD에 조작 안내를 붙인다: 빈 아이템 칸 "? 상자를 먹으세요", 아이템 보유 시 사용 키,
  코너 진입 시 드리프트 키. 4판째부터는 사라진다.
- 이벤트 피드: "드리프트 부스트!", "추월!", "명중!", "슬립스트림!"을 짧게 띄운다. 미션 진행도가
  오르면 같은 자리에 "아이템 5/8"처럼 띄운다. 코인 규칙은 바꾸지 않는다(문구만).

### 4.7 로비 단순화

- 큰 "레이스" 버튼 하나 + 차고 + 미션. 출석, 오늘의 도전, 기록, 설정은 작은 아이콘 줄로 내린다.
  기존 클래스 이름(`.single-toggle` 등)은 도구가 쓰므로 유지한다.
- 차고에 "이 기기에 자동 저장됩니다" 문구를 넣는다(Verse8 호스트 밖에서만).

### 4.8 CrazyGames 빌드와 이름

- 새 이름은 **Drift Kart**다. 브랜드를 빌드 설정으로 뺀다: CrazyGames 빌드는 "Drift Kart"
  (워드마크 "DRIFT" + 노란 번호판 "KART", 문서 제목, 한·영 문구), Verse8·원스토어 빌드는
  "Drift Dash GP" 그대로다.
- CrazyGames 타깃(예: `vite build --mode crazygames`, 출력 `dist-crazygames/`):
  - VX 결제 UI와 프리미엄 패스 문구를 숨긴다. 프리미엄 카트는 코인 해금만 보인다.
  - 보상형 광고 버튼(코인 2배, 미션 교체, 광고로 연속 접속 복구)을 숨긴다. Basic Launch 동안은
    광고가 꺼져 있다. 연속 접속이 하루 끊겼을 때는 광고 없이 1회 무료 복구로 둔다.
  - 온라인 패널을 숨긴다. 저장은 `localServer.ts`(브라우저 저장소)를 쓴다.
  - 빌드 크기 20MB 미만, 첫 화면까지 10초 미만을 확인한다.
- 제출 자료 초안을 `marketing/crazygames/`에 만든다: 한 문장 훅으로 시작하는 영어 소개,
  조작법(지금 빌드 기준, 카트 16·서킷 16), 태그 제안, 방향 Landscape, 썸네일·미리보기 영상 요구 사항.
  썸네일과 영상 제작, 포털 제출은 이 작업에 포함하지 않는다.

## 5. 하지 않는 것

- 배틀 모드, 그림 스타일 변경, UI "서킷 포스터" 재개편.
- push, Verse8 배포, CrazyGames 포털 제출. 전부 로컬에서 끝낸다.
- `package-lock.json`의 기존 변경은 건드리지 않는다. `verse8` 원격 주소의 토큰은 출력하지 않는다.

## 6. 검증

- `npm run typecheck`, `npm test`, `npm run build`, CrazyGames 타깃 빌드가 통과한다.
- `first-session.mjs`를 새 저장 상태로 돌려 확인한다(PC 1280×720, 폰 844×390, 한·영):
  - 클릭 없이 첫 레이스에 들어간다.
  - 첫 3판에서 플레이어가 리타이어되지 않는다.
  - 판마다 "새로 열림"이 하나 이상 나온다.
  - 결과 화면의 주 버튼이 다음 서킷으로 간다.
  - 폰 결과 화면이 스크롤 없이 보인다.
  - CrazyGames 빌드에 "VX", "WATCH AD", "Drift Dash" 문구가 없다.
- 기존 저장(코인·레이스 기록 있음)으로 열었을 때 서킷 16개가 전부 열려 있다.
- 브라우저 검증은 헤드리스 + 음소거.
