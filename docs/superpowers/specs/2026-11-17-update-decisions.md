## 2. 카트 외형 (전부 하기로 확정)

차체 실루엣 8종은 유지한다. 주행 물리는 바꾸지 않는다. 에셋 파일은 추가하지 않는다(전부 코드 생성).

| # | 바꿀 곳 | 내용 |
|---|---|---|
| 1 | 드라이버 | 8명이 같은 마네킹(캡슐 몸 + 공 헬멧, 색만 다름) → 레이서마다 헬멧 장식과 체형을 다르게. 예: 페넥 여우 귀, 브람 뿔·넓은 어깨, 로사 트럭 모자, 주노 번개 지느러미, 카이 서퍼 고글 |
| 2 | 번호 | 작은 번호판 → 코와 옆면의 큰 원형 번호판 (UI 번호판과 짝) |
| 3 | 바퀴 | 전부 같은 검은 원통 + 별 모양 휠 → 체급별 휠·타이어 (경량 얇은 스포크, 중량 접시형, 헤비 오프로드 돌기) |
| 4 | 앞모습 | 헤드라이트·그릴·범퍼로 차체마다 표정 |
| 5 | 공통 부품 | 체급별 엔진 크기·배기 모양, 시트 색 띠 |
| 6 | 드라이버 동작 | 코너에서 몸 기울이기, 아이템 피격 반응, 결과 화면 승리 포즈 |

헬멧 장식은 새 외형 종류로 만들어 진행 시스템의 획득 전용 보상으로 쓴다(왕관, 뿔, 프로펠러 등).
드라이버를 바꾸면 레이서 카드 썸네일을 다시 그려야 한다.

## 3. 주로 (입체 교차까지 전부 하기로 확정)

불만: "너무 타원형만 있다. 점프나 액티브한 주로가 있으면 좋겠다."
지금은 서킷 8개가 모두 닫힌 고리 하나(`TrackDefinition.controlPoints`)이고, 주로 위에는 부스트
패드, 아이템 상자, 고정 기둥(`obstacles`), 난간 없는 구간(`voidRanges`)만 있다. 공중 물리(`vy`,
중력, 착지 충격)는 `Kart.ts`에 이미 있다.

| # | 기믹 | 내용 |
|---|---|---|
| 1 | 점프 | 점프대, 끊긴 도로, 언덕 꼭대기에서 날기. 공중에서 드리프트 버튼 → 묘기 → 착지 부스트 |
| 2 | 움직이는 장애물 | 트램 건널목, 굴러오는 바위·눈덩이, 차단기. 레이스 시계로 움직여 모든 클라이언트에서 같은 위치 |
| 3 | 노면 구간 | 얼음(미끄러짐), 진흙·얕은 물(감속), 긴 부스트 띠, 옆바람 |
| 4 | 지름길 | 니트로가 있어야 통과되는 오프로드 길, 헤어핀을 가로지르는 위험한 점프 |
| 5 | 입체 교차 | 다리 위아래를 지나는 8자 주로. 주로 판정, AI 주행선, 미니맵을 함께 고쳐야 한다 |

서킷별 적용안:

| 서킷 | 넣을 것 |
|---|---|
| Sunny Circuit | 완만한 언덕 점프 1개 (입문용) |
| Coral Coast | 부두 점프대, 랩마다 넓어지는 밀물 구간 |
| Dune Drift | 연속 모래 언덕 점프, 옆바람 구간 |
| Frostbite Falls | 얼음 구간, 굴러오는 눈덩이 |
| Neon Nexus | 트램 건널목, 끊긴 고가도로 점프 |
| Magma Ridge | 굴러오는 바위, 균열 점프 |
| Switchback Pass | 낙석, 헤어핀 가로지르기 지름길 |
| Prism Skyway | 끊긴 도로 연속 점프 |

신규 서킷 2개: **스턴트 파크**(큰 점프대 3개 + 긴 부스트 띠), **크로스오버**(다리로 두 번 교차하는 8자).
새 서킷을 추가하면 `server.js`의 `TRACKS` 집합에도 넣어야 기록이 받아진다.

## 작업 규칙

- 사용자에게는 항상 한국어로 답한다.
- 브라우저 검증은 헤드리스 + 음소거. 헤드리스 Chrome에서 WebGL2는
  `--use-gl=angle --use-angle=metal --ignore-gpu-blocklist`로만 뜬다.
- 시작 전에 `docs/ARCHITECTURE.md`와 `CONTRACT.md`를 읽는다.
- `package-lock.json`에 커밋되지 않은 기존 변경이 있다. 건드리지 않는다.
- `verse8` 원격 주소에 GitLab 토큰이 평문으로 들어 있다. 출력하거나 공유하지 않는다.
